## **a)**

Pruebe la siguiente desigualdad para todo $n ≥ 4$.

$$ (n + 1)^{4} < 3n^{4} $$

Nota: No use el principio de inducción, simplemente use que la sucesión

$a_n = (1 + 1 n)^4$ es decreciente (es decir, $a_{n+1} < a_n$ para todo $n$ natural) y que $a^4 < 3$.

## **b)**

Usando el ítem anterior y el principio de inducción, pruebe que $3^n > n^4$ para todo número natural $n ≥ 8$.
