## Ichi

Pasemos a hablar acerca de nuestro asistente virtual al cual nombramos Ichi.

Ichi es un bot conversacional con el cual los usuarios pueden chatear en caso de que no sepan como realizar cierta acción.

Si bien el modelo de inteligencia artificial que usa Ichi para razonar no los creamos nosotros, lo que si hicimos fue usar una técnica para darle suficiente contexto para que sepa que es lo que puede hacer cada rol dentro de la plataforma.

Esto también nos ayuda a delimitar que tipo de preguntar puede response el bot, ya que si por ejemplo un usuario le pregunta como salio el ultimo partido de la selección argentina, el bot no tendría por que responderlo.

## Road map

Otra de las funcionalidades planeadas a futuro para la plataforma es la incorporación de cursos de capacitación personalizados, donde el sistema analiza el perfil del usuario, y a partir de algoritmos de machine learning se le recomienden cursos para que pueda enriquecer su perfil, todo esto con la finalidad de que el usuario tenga mejores oportunidades laborales.
